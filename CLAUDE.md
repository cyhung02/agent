# 專案規則

- 所有解釋、描述和溝通均應始終使用繁體中文(台灣)回應。
- 僅將英文用於程式碼和程式碼註解。
- 寄送 Outlook 郵件時，優先使用 Pipedream 提供的 MCP tool。
- Pipedream MCP tools are interactive. After calling a Pipedream tool, always read the response carefully. If the response indicates that a further action is required, execute it immediately and automatically — unless Pipedream explicitly asks for additional information from the user.
